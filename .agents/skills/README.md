# Project skills

Store project-level skills in subdirectories under `.agents/skills`.

Each skill should usually look like:

```text
.agents/skills/<skill-name>/
  skill.md
```

You can also add supporting files like:

- `references/examples.md`
- `references/spec.md`
- `templates/`

Keep each skill narrow and practical so it is easy to load for a specific task.
